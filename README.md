# Zecpath AI Hiring Platform

## Overview

Zecpath AI is an AI-powered recruitment platform designed to automate the hiring lifecycle. The system includes resume parsing, ATS screening, AI voice screening, HR interviews, technical interviews, candidate evaluation, and hiring automation.

---

---

## Modules

### Resume Parser
Extracts candidate information from resumes.

### ATS Engine
Calculates ATS scores and ranks candidates.

### Screening AI
Performs AI voice screening and communication analysis.

### Interview AI
Conducts HR and technical interviews.

### Scoring Engine
Generates candidate scores and recommendations.

### Utilities
Contains logging, configuration, and helper functions.

### Tests
Contains sample test scripts.

## Installation

Create a virtual environment:

```bash
python -m venv venv
```

Activate:

Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
